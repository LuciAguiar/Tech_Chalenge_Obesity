# Tech Challenge 4 - FIAP: Predição Comportamental de Obesidade

Este repositório contém a aplicação desenvolvida para o Tech Challenge 4. 
Utilizamos um modelo de Random Forest para prever o risco de obesidade baseado em hábitos alimentares e histórico familiar, descartando altura e peso para evitar vazamento de dados.

🔗 **Link para a aplicação na nuvem:** [Cole o seu link do Streamlit aqui]

## Estrutura do Projeto
- `app.py`: Código fonte da aplicação Streamlit.
- `Obesity.csv`: Dataset original.
- `dicionario_obesity_fiap_tc4.pdf`: Dicionário de dados.
- `.pkl`: Arquivos binários do modelo treinado.
